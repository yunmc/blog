# 情趣用品业务战略整合备忘录

## 一、结论先行

如果只挑最有想象力、也最可能做成长期平台价值的 3 个方向，我会选：

### 1. 亲密科技平台
把“玩具、连接、控制、AI、内容、会员”做成一个长期系统。

这不是单点功能，也不是一次性卖货，而是围绕设备建立一个持续使用、持续付费、持续更新的亲密体验系统。

### 2. 行业基础设施
服务品牌和渠道，做操作系统、SaaS、SDK、内容层。

也就是不只做某一个品牌的功能升级，而是成为这个行业共同依赖的一层：设备接入、App、控制、内容分发、品牌后台、数据系统，都可以沉淀为基础设施。

### 3. 关系场景消费
不是卖用品，而是卖“异地情侣、纪念日、沉浸体验、自我探索”这些可重复消费的场景。

真正有复购和长期价值的，不是一个玩具本身，而是围绕关系、情绪、互动和新鲜感形成的持续消费场景。

---

## 二、为什么这 3 个方向最重要

### 1. 从“卖用品”升级为“卖长期关系系统”
传统情趣用品更像货架生意，本质是 SKU、生意效率、渠道分发。

但如果加入连接、控制、AI 和内容，业务就会从一次性购买，升级成长期关系系统：
- 设备是入口
- App 是连接器
- AI 是体验增强器
- 内容是留存工具
- 会员是持续收入来源

这就是“亲密科技平台”的价值。

### 2. 从“品牌生意”升级为“行业底层能力”
如果你们只给某些品牌做项目，天花板会卡在人力和项目制。

但如果把共性能力抽象出来，就能逐步形成行业基础设施：
- 统一接入协议
- 统一 App 框架
- 统一控制 SDK
- 统一内容层
- 统一品牌后台
- 统一会员与数据系统

一旦多个品牌接入，你们就不再只是供应商，而是行业中的平台型角色。

### 3. 从“卖功能”升级为“卖关系场景”
用户买的不是某个按钮，也不是某段 AI 对话。

用户真实购买的是：
- 异地连接
- 节日仪式感
- 新鲜体验
- 情绪陪伴
- 自我探索
- 情侣共创互动

这意味着最有价值的 2C 方向，不是泛成人聊天，而是围绕可重复消费场景做体验系统。

## 四、五层分别在赚什么钱

### 第 1 层：硬件层 / 连接层
这是最底层，也是最容易先拿到订单的一层。

你卖的不是“AI”，而是：
- 芯片升级
- 通信模组
- 协议适配
- 配对与连接能力
- 包装二维码接入能力

这一层的钱通常来自：
- 接入费
- 方案费
- 定制开发费
- 按机型收费
- 按出货量收费

这层的特点是：容易启动，但容易项目制，天花板有限。

### 第 2 层：软件层 / 服务层
这一层开始把一次性交付，变成持续服务。

核心能力包括：
- App
- 设备管理
- 远程控制
- 账号体系
- 云同步
- 风控、审核、权限与隐私

这一层的钱通常来自：
- 年服务费
- 按激活设备收费
- 维护费
- SDK 授权费

这层的意义在于：你开始从“做完一个项目”变成“持续服务一个品牌”。

### 第 3 层：内容层 / 体验层
这一层是把硬件变成“长期使用入口”的关键。

核心内容包括：
- AI 聊天
- AI 电话 / 语音互动
- 互动剧本
- 角色包、声线包
- 设备动作编排
- 情侣场景包
- 个性化推荐

这一层的钱通常来自：
- 内容包付费
- 角色包付费
- 场景包付费
- 会员订阅
- 增值功能

这层最关键的不是技术，而是：

**用户有没有理由回来反复使用。**

### 第 4 层：运营层 / 品牌增长层
这一层开始真正建立品牌方离不开你的理由。

核心能力包括：
- 白标 App
- 品牌后台
- 用户分层
- 数据分析
- 转化漏斗
- CRM / 私域召回
- 会员体系
- A/B 测试

这一层的钱通常来自：
- SaaS 费
- 年框费
- 增长服务费
- 数据服务费
- 联合运营分成

这一层最重要的是：

**你不再只是“给客户做东西”，而是“帮客户赚钱”。**

### 第 5 层：生态层 / 平台层
这一层才是最大想象力所在。

核心能力包括：
- 创作者生态
- UGC / PGC 角色市场
- 内容分发系统
- 开放 API / SDK
- 多品牌接入
- 联盟分成
- 行业标准

这一层的钱通常来自：
- 平台费
- 分成抽佣
- SDK 授权费
- API 调用费
- 创作者市场抽成
- 生态合作收入

一旦跑通，你就不是一个“情趣用品服务商”，而是这个行业的一层基础设施。

## 五、你们现在大概在哪一层

按你前面描述的业务，你们已经跨过前三层：

- 第 1 层：芯片升级、二维码、设备接入
- 第 2 层：App、配对、控制、服务能力
- 第 3 层：AI 聊天、AI 电话、AI 控制玩具

这说明你们已经不是普通硬件代工，也不是普通软件外包。

但接下来真正决定天花板的，不是再加几个功能，而是能不能继续往上走：

- 补齐第 4 层：品牌运营系统
- 试探第 5 层：创作者 / 内容 / 多品牌生态

换句话说：

**你们已经有“产品雏形”，下一步要做的是“平台结构”。**

---

## 六、每一层真正要解决的问题

### 第 1 层要解决什么
设备能不能稳定连接、低成本接入、快速复制。

### 第 2 层要解决什么
用户能不能顺畅激活、稳定使用、持续留在系统里。

### 第 3 层要解决什么
用户为什么回来，为什么愿意付费。

### 第 4 层要解决什么
品牌为什么持续续费，为什么越来越依赖你。

### 第 5 层要解决什么
创作者、品牌、用户三方是否能在你这里持续交易和增长。

---

## 七、你们下一步最值得补的两层

### 先补第 4 层：运营层
这是最现实、也最能提升估值和议价权的一步。

建议优先做：
- 品牌后台
- 设备激活漏斗分析
- 扫码率 / 激活率 / 配对率看板
- 内容使用率看板
- 复购与召回工具
- 会员与付费分析

只要你能告诉品牌方：
- 哪个 SKU 更容易被扫码
- 哪类用户更容易激活
- 哪种 AI 玩法更容易复用
- 哪种付费包更容易转化

你就从供应商变成增长伙伴了。

### 再试探第 5 层：生态层
但不要一上来做完全开放的成人 UGC 社区。

更稳的方式是：
- 先做精选创作者计划
- 先做结构化内容包，而不是无限开放角色
- 先做内容分发，不急着做社交
- 先做消费市场，不急着做开放创作平台

也就是：

**先做“内容生态”，再决定要不要做“社区生态”。**

## 八、一条推荐的演进路径

### 阶段一：解决方案公司
卖硬件接入、App、AI 能力、控制能力。

### 阶段二：平台型公司
把通用能力抽象成标准产品、白标系统和品牌后台。

### 阶段三：运营型公司
帮助品牌提升激活、留存、复购、ARPU。

### 阶段四：生态型公司
引入创作者、内容市场、多品牌协同、API / SDK。

### 阶段五：行业基础设施公司
成为“成人硬件行业的操作系统 + 内容层 + SaaS 层”。

---

## 九、战略重点：不是继续堆功能，而是往上占层

你们真正的天花板，不在于“还能加多少 AI 功能”，而在于：

**能不能从卖设备增强能力，走到掌握设备层、内容层、运营层和生态层。**

所以短期看，最重要的是：
- 标准化底层接入能力
- 打磨设备 companion app
- 跑通内容付费和设备活跃度
- 搭品牌后台与增长指标体系

中期看，最重要的是：
- 白标化、模块化、可复制
- 多品牌接入
- 数据系统沉淀
- 内容包和角色包的分发机制

长期看，最重要的是：
- 创作者生态
- 多边市场
- SDK / API
- 行业标准

## 十、最后一句话

如果只把它看成“情趣用品升级”，想象力会停留在卖货和功能层。

如果把它看成“亲密科技行业的底层平台”，你们未来真正能做的就不只是：
- 卖硬件
- 卖 App
- 卖会员

而是还能做：
- 平台费
- 授权费
- SaaS 费
- 内容分成
- 创作者生态
- 多品牌运营
- 自有品牌孵化

这才是这个业务真正大的空间。
