# andrej-karpathy-skills 全景解析

## 1. 项目简介

**andrej-karpathy-skills** 是一个非常克制、非常实用的项目。它没有堆很多花哨能力，而是把 Andrej Karpathy 对 LLM 编码常见问题的观察，收敛成一套简洁的 Claude Code 规则。

项目核心是四条原则：

1. 先想清楚再写。
2. 先求简单，不要过度设计。
3. 只做必要改动，不碰无关区域。
4. 用可验证目标驱动执行，而不是写完就算。

## 2. 核心价值

- **非常适合做默认工程准则**。
- **直击 LLM 编码常见失误**，比如擅自假设、过度设计、误改无关代码、没验证就宣布完成。
- **内容简短但约束力强**，比大型规则库更容易长期保持有效。
- **便于嵌入现有环境**，可以合并进 CLAUDE.md 或其他 agent 指令文件。

## 3. 适合的场景

1. **给 AI 编码建立底层行为规范**。
2. **团队统一 Agent 基线规则**。
3. **降低 AI 乱改和过度实现的风险**。
4. **为复杂任务建立更强的验证意识**。

## 4. 相关建议

- 如果你还没有一套明确的 Agent 工程准则，这个项目很适合作为起点。
- 最值得吸收的不是安装方式，而是四条原则背后的取舍逻辑。
- 可以把它作为根规则，再叠加你自己的项目约束，而不是拿更复杂的大仓库直接开局。
- 如果你已经有很多规范，这个项目也适合用来“做减法”，帮助你回到更稳定的基本盘。
- 这类规则最适合服务于中等以上复杂任务；对极小改动则可以适当放宽，不必机械执行。

## 5. 一句话总结

andrej-karpathy-skills 的强点在于简单而有效，它不是功能仓库，而是一套能明显减少 AI 工程失误的**底层行为约束**。
